PageLens examples

The same lib.js added to different kinds of websites with two script tags, and no other code changes. Open one, click the 💬 button at the bottom right, and ask about the page: PageLens points to the right place or answers from the page's text, and says so when something isn't on the page.

Online store (demo)

Plain HTML page built for PageLens

  • is delivery free?
  • what would the power bank cost with express delivery?
  • do you sell laptops?

Admin dashboard

React + Vite app (shadcn-admin)

  • what is the total sales this month?
  • who was the biggest customer in recent sales?
  • what is our profit?

Shopping site

React + Vite app, products loaded from an API

  • do you sell jewelry?
  • how much is the backpack?
  • where do I sign in?

Restaurant

React + Vite one-page site

  • What are your opening hours on Saturday?
  • how do I book a table?
  • do you have vegan dishes?
